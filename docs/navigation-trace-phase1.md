# 临时导航诊断版（第一阶段）

本分支仅添加诊断功能，未修复滚动行为。请勿合并到正式版。

## 安装与操作

1. 打开本分支 PR 的 Actions 检查，下载验证通过的扩展 ZIP，解压到独立文件夹。
2. 在 Chrome 扩展管理页开启开发者模式，使用“加载已解压的扩展程序”，选择解压的目录。测试时请禁用此前安装的 LunaTOC，避免重复注入。
3. 打开 LunaTOC 设置，找到“临时导航诊断（测试版）”，开启日志开关。
4. 刷新 ChatGPT 对话页，打开一段较长的对话。测试：底部 → 第二条目录；顶部 → 底部；第一条目录 → 底部。每次操作后等待约 5 秒，建议每种场景执行三遍。
5. 回到设置页，点击“导出诊断 JSON”。请同时记录看见回答消失、重新出现的具体操作顺序。导出后关闭诊断开关，并点击“清空诊断日志”。

## 数据范围与限制

- 默认关闭；每次跳转采集约 16 秒。每个标签页会话最多 2500 条事件，自动只保留最近 8 组且每组不超过 48 小时。
- 记录各层时间戳、滚动坐标、原生滚动控制器缓存、目标 turn 和 Assistant DOM 的挂载与布局状态。
- 不持久化提问正文、回答正文、原始 messageId、账号标识和会话 URL。
- 导出通过浏览器本地下载完成，不发送到任何远程服务器。
- 模拟 Chromium 浏览器测试无法替代真实 ChatGPT 页面的虚拟列表故障复现。
