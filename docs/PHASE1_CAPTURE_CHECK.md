# 阶段一：共享提取与时间边界检查

本阶段继续使用 `codex/phase0-feasibility-20261126`。新增能力只做本地只读检查，不启用持续记录、不建立正式消息库、不生成 DOCX。

## 实现范围

- 共享消息身份、角色、版本比较、父节点、正文、附件和有序图片引用模型。基础 Markdown 块使用原始文字偏移，保留代码空白；复杂格式转换留给文档阶段。
- 单独的检查读取不合并到点击前已经启动的目录刷新；请求不使用缓存，支持独立取消，并限制并发。
- 复用已有页面数据与消息流事件，识别已观察到的末节点、生成请求和结束信号；未知状态不作为允许正式导出的依据。
- 页面格式只通过明确的消息身份映射，不按顺序或相同正文猜测。未挂载内容不推定为已验证。
- 任务绑定账号验证代次、当前对话和固定范围，支持超时、主动停止、上下文失效及迟到响应丢弃。任务进行时只临时保持目录展开，不修改固定偏好。
- 原始图片读取限制来源、字节、队列和并发；同一地址合并请求，不携带跨站凭据，不申请新图片域名权限。只取一张当前视口中已加载的图片并验证解码，不宣称已取得原图或全部历史图片。
- 报告只保留统计和自然语言结论，包含唯一测试构建标识；没有正文、文件名、图片、真实身份、地址或凭据。不写入浏览器持久化存储，不接入云同步。

## 必须区分的结论

1. 路径完整：数据返回终止分页，当前有效路径可以整理。
2. 固定范围一致：两次读取中的固定前缀一致，追加后代不混入。
3. 点击瞬间快照：仍未验证。当前来源没有能绑定点击边界的原子版本证明。

即使前两项通过，也不会允许正式点击快照导出。分页混合版本仍可能发生；比较不一致时停止，比较一致也不排除未观察到的修改后恢复。原阶段 0 的测试保留为现有目录读取风险复现；阶段一新增检查管线拒绝不一致结果及正式导出门禁的测试，没有把目录的分支标记冒充内容一致性。

## 用户只需通过扩展进行检查

安装对应 CI 产出的 ZIP，解压后在 Chrome/Edge 的扩展管理页加载或更新扩展，刷新 ChatGPT 页面。等待已登录页面初始化，打开 LunaTOC，点击标题与搜索之间的勾选图标，进入“对话功能与时间边界检查”。也可在设置页点击“运行功能检查”。无需开发者工具或脚本。

| 场景 | 操作 | 需要观察的结果 |
|---|---|---|
| 正常长对话 | 在含长消息、代码、可见图片的对话点击“快速检查” | 结束后可导出报告；报告分别说明路径、正文、图片和快照证据 |
| 新增消息 | 选择“新增消息”，开始时间边界检查；等待提示范围已固定；发送一条消息；点击“完成检查” | 新增消息不进入固定范围，并显示检测到新增 |
| 修改历史 | 在专用测试对话选择“修改历史提问”，开始检查；等待固定后修改旧提问 | 检测变化并停止；未检测到时标为未验证，不能判通过 |
| 回答版本 | 选择“重新生成或切换回答版本”，开始检查；等待固定后切换历史回答版本 | 检测路径或内容变化并停止；未完成操作不判通过 |
| 切换对话 | 选择“切换其他对话”，开始检查；等待固定后打开另一对话 | 原任务停止；同一页的检查面板保留脱敏报告 |
| 取消 | 开始检查后点击“停止检查” | 停止请求和临时任务，能够导出取消报告 |

每次检查结束后点击“导出检查报告”；多项检查分别导出文件。检查最多三分钟，等待页面操作期间不轮询接口。关闭检查面板会释放当前任务和报告；刷新、离开页面后的未导出报告不持久保存。历史修改与版本切换测试使用可以修改的专用测试对话，扩展不会替用户操作真实消息。

操作按钮固定在检查面板底部，说明与状态区域单独滚动。右上角“×”关闭检查；导出本轮报告后，点击“重新检查”开始下一轮。面板会根据文字大小和窗口可用高度调整，目录底部留白保留在目录自己的滚动区域内。

如果初次读取前没有可靠观察到末消息，报告会明确说明只固定了首次完整读取的范围，不能把它称为点击时刻范围。没有可见图片时标为未验证，不要求用户重复提交旧报告。

## 验证与限制

- 本地已执行类型检查、单元测试和构建。完整测试曾因并发运行导致原有 2000 条目录性能用例超过默认五秒；限制工作进程后完整通过，不修改原性能断言。
- 本地系统 Chromium 只有启动脚本，实际程序缺失；Playwright 浏览器下载被网络拒绝。模拟浏览器扩展加载由仓库 CI 运行，结果以对应提交的 CI 为准。
- 新增浏览器用例通过真实扩展入口执行快速检查、追加排除、历史修改、回答版本、对话切换和取消报告；页面与接口均为已知合成样本，不访问真实 ChatGPT。
- 真实 ChatGPT 的长消息来源、页面身份映射、生成信号和图片域名仍需上述必要操作验证；合成样本通过不能替代这些结果。
- 现有非导出功能保持原有逻辑；没有新增常驻全量扫描或正文存储。

下一阶段是阶段二的持续记录、存储与清理。真实页面报告用于确认阶段一接口契约和适配问题；点击瞬间原子快照仍单独阻断正式导出承诺，不阻断不依赖该证明的存储基础开发。
