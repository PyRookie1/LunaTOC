# 账号身份与本地数据隔离

LunaTOC 将 ChatGPT 账号 ID 作为本地数据的归属标识。账号 ID 必须由扩展的隔离脚本调用 ChatGPT 当前登录会话接口读取；未验证身份时，不允许创建、编辑、删除账号数据。

## 数据范围

- **Tips 提示词**：每条记录保存 `ownerId`，读取时仅展示当前账号的记录。
- **提示词使用统计**：每条统计通过提示词 ID 关联到带 `ownerId` 的提示词。读取时按当前账号过滤；更新、删除和清空时再次检查提示词是否属于请求账号。
- **自定义目录名称**：每个会话记录都附带 `ownerId`。不能将已有账号的目录别名写成另一个账号的数据。
- **主题与侧边栏偏好**：保存在按 ChatGPT 账号 ID 分组的记录中；邮箱仅用于界面显示，不能代替账号 ID。
- **本地备份**：每条提示词、目录别名和账号设置都必须具备合法的账号归属。缺少归属或归属冲突时，拒绝导入或写入，而不是猜测归属。

## 账号切换

已打开的 ChatGPT 页面在导航和重新获得焦点时重新核对账号。账号变化或核验失败时，不继续使用原账号的编辑权限；正在等待的写入会在写入前或收到确认时再次检查当前账号。不同 ChatGPT 账号的本地数据保持分离。

## 多设备与云同步绑定

同一浏览器可在本地管理多个 ChatGPT 账号的数据，各账号的 Tips、目录别名和偏好按已验证的 `ownerId` 隔离。账号设置创建前由后台重新核验发起操作的 ChatGPT 标签页。

LunaTOC 云账号是独立的 Firebase UID。**本地数据并不因为用户登录某个 LunaTOC 云账号就全部上传**：每个 ChatGPT 账号必须在设置页主动绑定对应的 LunaTOC 云账号，只有绑定 UID 与当前已登录 UID 完全相同才可同步。自动同步跳过其他账号；将 Firebase A 切换为 B 时不会自动复制 A 的已绑定数据。用户可针对当前 ChatGPT 账号解除本机绑定，再有意识地绑定另一个云账号；解绑不删除本地数据、既有远端数据和备份。

跨设备使用同一 Firebase 登录身份及同一 ChatGPT 登录身份后，在新设备主动绑定对应账号并开启同步。绑定关系为本地控制信息，不进入 Firestore 快照或备份。Firestore 路径同时包含 Firebase UID 与 ChatGPT 账号 ID 摘要，安全规则隔离不同 Firebase UID。

## 验收边界

自动化测试验证本地身份、绑定和云端安全规则。模拟的跨设备流程不等于已经完成真实 ChatGPT 网站或生产 Firebase 的人工验收；正式发布前按 [云同步说明](FIREBASE_SYNC.md) 与 [发布验收清单](RELEASE_CHECKLIST.md) 执行完整验证。
