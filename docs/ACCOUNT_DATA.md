# 账号身份与本地数据隔离

LunaTOC 将 ChatGPT 账号 ID 作为本地数据的归属标识。账号 ID 必须由扩展的隔离脚本调用 ChatGPT 当前登录会话接口读取；未验证身份时，不允许创建、编辑、删除账号数据。

## 数据范围

- **Tips 提示词**：每条记录保存 `ownerId`，读取时仅展示当前账号的记录。
- **提示词使用统计**：每条统计通过提示词 ID 关联到带 `ownerId` 的提示词。读取时按当前账号过滤；更新、删除和清空时再次检查提示词是否属于请求账号。
- **自定义目录名称**：每个会话记录都附带 `ownerId`。不能将已有账号的目录别名写成另一个账号的数据。
- **主题与侧边栏偏好**：保存在按 ChatGPT 账号 ID 分组的记录中；邮箱仅用于界面显示，不能代替账号 ID。
- **本地备份**：每条提示词、目录别名和账号设置都必须具备合法的账号归属。缺少归属或归属冲突时，拒绝导入或写入，而不是猜测归属。

## 账号切换

已打开的 ChatGPT 页面在导航和重新获得焦点时重新核对账号。账号变化或核验失败时，不继续使用原账号的编辑权限；正在等待的写入会在写入前或收到确认时再次检查当前账号。不同 ChatGPT 账号的本地数据保持分离。

## 多设备与云端准备

同一个浏览器可以使用多个 ChatGPT 账号。一个账号在不同设备上的数据归属标识保持相同，但**本阶段不自动跨设备传输数据**。

下一阶段接入 Firebase 时，还需独立的 Firebase 登录身份（UID）控制云端资源访问：ChatGPT 账号 ID 用于用户自己的数据分组，不能单独作为 Firebase 身份凭证。云端路径应同时限定 Firebase UID 和 ChatGPT 账号 ID，并以服务器端安全规则隔离不同 Firebase 用户。

## 验收边界

本阶段使用账号模拟测试、存储单元测试和 Chromium 模拟页面测试。上述测试确认扩展的身份检查、写入条件和可见数据范围；**不表示已经验证真实 ChatGPT 网站上所有账号切换场景，也不表示跨设备同步已经实现**。
