# LunaTOC v1.0.0 — 重新构建（2026-11-03）

本次重新发布保留 **v1.0.0** 版本号，使用最新 `main` 分支重新构建扩展并替换已有 v1.0.0 安装包和 SHA-256 校验文件。

## 变更

- **彻底移除「已分析」状态隐藏功能**：不再监听、标记或隐藏 ChatGPT 思考详情中的任何「已分析」状态文字，恢复 ChatGPT 原生显示。
- 保留对话目录、回答标题导航、目录搜索、活动分支识别、Markdown 粗体修复、Tips 提示词库、侧边栏布局、本地备份和可选云同步。
- 不增加用户设置开关，也不改变 GPT 的实际思考过程。

## 版本说明

- 扩展清单、`package.json` 和锁文件版本均为 `1.0.0`。
- 由于是对既有 v1.0.0 的重新构建，**原 v1.0.0 安装包及其 SHA-256 校验值已被替换**，请使用本页面最新附件。
- 原 v1.0.1 Release 仍保留作历史记录；本次重建的 v1.0.0 是恢复 ChatGPT 原生思考状态显示的版本。
