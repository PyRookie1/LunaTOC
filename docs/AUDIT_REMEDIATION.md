## 数据兼容性

- 扩展版本和云端快照结构保持现有版本，Firestore 规则无需部署变更。
- 备份写出版本为 2，解析器兼容版本 1；v1 文件没有源设备删除标记，迁移前应重新导出 v2。
- 恢复合并删除状态；跨账号归属冲突拒绝整次操作。已确认删除的整个会话不能恢复别名。
- 云账号令牌、本机绑定、完整聊天正文均不加入备份。
- 新会话的未确认 URL 不接管旧消息；服务端 ID 确认后再恢复对应目录。迁移测试显式携带该确认，替换原来把任意下一 URL 视作合法迁移的假设。
