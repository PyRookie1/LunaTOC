# 本地数据备份与恢复

LunaTOC 的设置页面提供本地 JSON 备份与恢复。备份文件在浏览器中生成，不会上传到 LunaTOC 服务器，也不包含 ChatGPT 对话正文或浏览器登录凭证。

## 备份内容

备份文件名为 `lunatoc-backup-YYYY-MM-DD.json`，当前备份格式版本为 1。文件可包含：

- 已保存的 Tips 提示词及其账号归属。
- 提示词使用统计。
- 自定义目录名称及对应的 ChatGPT 账号和会话标识。
- 按账号保存的主题与侧边栏偏好。

备份不包含完整对话正文、浏览器会话存储、账号登录凭证、兼容性诊断状态或未知存储键。备份文件可能包含私人提示词和会话标识，不应公开分享。

## 导出

1. 打开 LunaTOC 弹出窗口并进入「设置」。
2. 在「本地数据备份与恢复」中选择导出。
3. 将下载的 JSON 文件保存在安全的位置。

## 恢复

1. 在设置页面选择备份文件。
2. LunaTOC 会先检查文件格式、字段、账号归属、重复 ID、文件大小和数据结构；验证失败时不会写入数据。
3. 选择「合并」或「覆盖」，检查预览并确认操作。
4. 恢复完成后刷新已打开的 ChatGPT 标签页，以便重新读取数据。

**合并**会保留本地和备份中不同的有效记录；同一提示词 ID 或会话若属于不同账号，操作会被拒绝。**覆盖**会替换备份范围内的数据，并删除不在备份中的目录别名；不属于备份范围的其他存储键保持不变。

恢复操作会先检查本地存储容量，并在写入后核对结果。若写入失败，扩展会尝试恢复受影响的数据。浏览器存储持续出错时，自动回滚也可能失败，因此重要数据应保留独立备份。
