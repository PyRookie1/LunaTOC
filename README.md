# LunaTOC

LunaTOC 是一款面向 ChatGPT 网页端的开源浏览器扩展，支持 Chrome 和 Edge，提供长对话目录、回答标题导航、Tips 提示词管理、页面显示优化、个性化设置及跨设备数据同步等功能。

## 功能

- **自动生成目录**：根据当前会话中的用户提问生成目录，实时跟踪并高亮当前位置。
- **回答标题导航**：从 ChatGPT 回答中提取最多三级标题，支持目录展开、收起及章节快速定位。
- **提问快速定位（核心功能）**：点击目录项跳转至对应提问，支持长对话及虚拟滚动场景。
- **活动分支识别**：根据 ChatGPT 消息关系识别当前活动分支，并展示对应的对话目录。
- **目录搜索**：通过关键词筛选当前会话中的提问。
- **自定义目录名称**：为会话中的问题设置本地显示名称，不修改 ChatGPT 的原始消息。
- **Tips提示词库**：支持提示词的添加、编辑、删除、搜索、排序、内容预览及快捷复制，支持 Markdown 格式导入与导出。
- **提示词快捷调用**：在 ChatGPT 输入框中输入 # 或 //，搜索并插入已保存的提示词；支持通过右键菜单将目录中的提问保存至 Tips。
- **多账号数据隔离**：自动识别当前 ChatGPT 登录账号，独立保存各账号的 Tips、目录别名及偏好设置。
- **本地备份导出恢复**：支持通过 JSON 文件备份和恢复提示词、目录别名、使用统计及账号偏好。
- **可选云同步**：通过独立的 LunaTOC 云账号绑定 ChatGPT 账号，自动同步 Tips、目录别名及主题与布局偏好。
- **兼容性警告**：可选检测 ChatGPT 关键接口及页面结构变化，在检测到不兼容情况时提供警告。

## 功能

- **粗体异常修复**：自动修复 ChatGPT 回答中的 Markdown 粗体显示异常，支持历史消息、新生成消息及动态加载的消息。
- **隐藏分析区块**：隐藏 ChatGPT 回答中的分析区块及相关工具执行结果，减少非正文内容对阅读的干扰。

额外功能默认开启，可在 LunaTOC 设置中独立开启或关闭。

## 安装与开发

1.从 [最新正式版](https://github.com/PyRookie1/LunaTOC/releases/latest) 下载 LunaTOC 的 ZIP 扩展安装包并解压；

2.在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`，

3.启用开发者模式，点击「加载已解压的扩展程序」，选择解压后的扩展文件夹；

4.打开或刷新 ChatGPT 网页，开始使用 LunaTOC。

## 支持范围与限制

- 采用 Chrome Manifest V3 扩展规范，支持 Chrome 和 Edge，目标站点为 chatgpt.com 和 chat.openai.com。
- 对话目录、回答标题导航及页面显示优化依赖 ChatGPT 的页面结构与会话接口；ChatGPT 网页更新后，扩展可能需要进行适配。
- 回答标题仅从当前已加载的回答中提取；未加载的历史消息需要完成加载后才能进行标题导航。
- 扩展默认使用本地存储。云同步需要用户主动开启、完成邮箱验证并绑定对应的 ChatGPT 账号，跨设备同步需使用相同的 LunaTOC 云账号和 ChatGPT 账号。详见 [LunaTOC 云同步](docs/FIREBASE_SYNC.md)。

## 隐私

扩展会读取生成目录所需的 ChatGPT 页面内容，并通过 ChatGPT 自身的同源登录接口识别账号。默认扩展数据保存在本地浏览器；用户主动启用后，选中账号的 Tips、目录别名与偏好会上传到 LunaTOC 维护者统一管理的 Firebase 项目。项目不包含遥测或广告追踪。详见 [隐私说明](PRIVACY.md)。
