# LunaTOC

LunaTOC 是一款面向 ChatGPT 网页端的开源浏览器扩展，支持 Chrome 和 Edge，提供长对话目录、回答标题导航、Tips 提示词管理、页面显示优化及跨设备数据同步等功能。

## 功能

- **自动生成目录**：按用户提问生成可搜索的目录，并跟踪当前问题。
- **回答标题导航**：从GPT回答中提取三级标题，支持展开、收起。
- **提问快速定位（核心功能）**：点击目录项跳转至对应提问，支持长对话及虚拟滚动场景。
- **活动分支识别**：根据 ChatGPT 提供的消息关系展示当前回答分支。
- **支持目录搜索**：通过关键词筛选当前会话中的提问。
- **自定义目录名称**：为会话中的问题设置本地显示名称，不修改 ChatGPT 的原始消息。
- **Tips提示词库**：保存、管理、导入和导出常用提示词，并支持输入补全。
- **本地备份导出**：导出或恢复提示词、目录别名、使用统计和账号偏好。
- **兼容性警告**：可选检查 ChatGPT 关键接口和页面标记变化，并在检测到不匹配时提示。
- **可选云同步**：云账号绑定，同步 Tips、目录别名与偏好。

## 功能

- **粗体异常修复**：自动修复回答中的 Markdown 粗体显示异常，支持动态加载的消息。
- **隐藏分析区块**：隐藏回答中的分析区块及相关工具执行结果，减少非正文内容对阅读的干扰。

## 安装与开发

1.从 [最新正式版](https://github.com/PyRookie1/LunaTOC/releases/latest) 下载 `lunatoc-v1.1.2.zip`；

2.在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`，启用开发者模式并加载解压后的文件夹。

## 支持范围与限制

- 支持 Chrome Manifest V3，目标站点为 `chatgpt.com` 和 `chat.openai.com`。
- 目录和标题导航依赖 ChatGPT 的页面结构与会话接口；网页更新后，扩展可能需要适配。
- 目录标题只从当前已加载的回答中提取；远距离导航可能需要等待历史内容加载。
- 默认仅本地保存；说明见 [LunaTOC 云同步](docs/FIREBASE_SYNC.md)。

## 隐私

扩展会读取生成目录所需的 ChatGPT 页面内容，并通过 ChatGPT 自身的同源登录接口识别账号。默认扩展数据保存在本地浏览器；用户主动启用后，选中账号的 Tips、目录别名与偏好会上传到 LunaTOC 维护者统一管理的 Firebase 项目。项目不包含遥测或广告追踪。详见 [隐私说明](PRIVACY.md)。
